About this project

A customer churn prediction and analytics system built as a data analytics and machine learning internship project.

What it does

Telecom companies lose revenue when customers leave. This system estimates each customer's probability of churning, shows why, and lets analysts explore the patterns behind churn so retention teams can act early.

Analysts can explore customer data, compare models, enter a new customer to get a churn probability with the main contributing factors, and review the customers most at risk.

Pipeline

Raw dataCleaningMissing valuesEDAFeature engineeringEncoding and scalingTrain/test splitModel trainingEvaluationSelectionSaved modelAPIWeb app

Imputation, encoding and scaling live inside one scikit-learn Pipeline fitted on the training split only, so the same steps run at prediction time and nothing leaks from the test set.

Limitations

  • The public dataset is a single snapshot with no dates, so the model cannot learn seasonality or changes over time.
  • Explanations show associations learned by the model, not proven causes.
  • The “Likely to Churn” label uses a cutoff below 50% (tuned for F1 on training data) so more churners are caught; the probability itself is not re-weighted.
  • Risk bands are business rules and should be tuned to the retention budget.
